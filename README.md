# Java Wordle4j — игра «Угадай слово» на Java

**Java Wordle4j** — учебная консольная реализация игры Wordle на русском языке. Игроку нужно угадать случайное пятибуквенное слово за **6 попыток**, ориентируясь на подсказки о совпадении букв.

Проект создан на основе учебного репозитория Яндекс Практикума для практики Java Core, алгоритмов, работы с файлами, коллекциями, исключениями и тестирования.

## Возможности

- Случайный выбор пятибуквенного слова из русскоязычного словаря.
- Проверка вводимых слов по словарю и контроль формата ввода.
- До шести попыток на угадывание слова.
- Подсветка результата с помощью символов `+`, `^` и `-`.
- Корректный учёт повторяющихся букв при сравнении слов.
- Подсказка по нажатию `Enter` без расходования попытки.
- Подбор подсказок с учётом предыдущих попыток и кеширование отфильтрованных вариантов.
- Отображение результата игры и количества использованных попыток.
- Запись технических событий в файл `wordle.log`.

### Как читать результат

| Символ | Значение |
|---|---|
| `+` | Буква есть в загаданном слове и стоит на правильном месте |
| `^` | Буква есть, но находится на другой позиции |
| `-` | Буква отсутствует или её дополнительные вхождения не подходят |

Например, для загаданного слова `герой` и попытки `гонец` алгоритм формирует шаблон `+^-^-`.

## Технологии

- **Java Core** — классы, инкапсуляция и обработка исключений.
- **Коллекции** — `List`, `Set`, `Map`, `HashSet`, `HashMap`.
- **Streams API** — фильтрация словаря.
- **Java I/O** — чтение словаря в UTF-8 и запись логов.
- **Регулярные выражения** — проверка пользовательского ввода.
- **JUnit 5** — модульные и интеграционные тесты.

В проекте нет Spring, базы данных и Maven/Gradle. Библиотеки JUnit приложены в каталоге `lib/`.

## Как запустить игру

**Требования:** установленный JDK. Компиляция и запуск проверены на **Java 21**.

Файл `words_ru.txt` должен находиться в **текущей рабочей директории** при запуске (обычно это корень репозитория).

### Через терминал (Linux/macOS)

Из корня репозитория:

```bash
javac -encoding UTF-8 -d out/classes src/ru/yandex/practicum/*.java
java -cp out/classes ru.yandex.practicum.Wordle
```

Далее вводите русские слова из пяти букв. Для получения подсказки просто нажмите `Enter`.

### Через IntelliJ IDEA

1. Откройте репозиторий в IntelliJ IDEA.
2. Укажите установленный JDK.
3. Запустите `main()` в классе `ru.yandex.practicum.Wordle`.
4. Если появится ошибка загрузки словаря, установите **Working directory** равной корню проекта, где находится `words_ru.txt`.

## Словарь и правила

Файл `words_ru.txt` содержит исходный набор русских слов. При загрузке программа оставляет только слова из **5 русских букв**, переводит их в нижний регистр, заменяет `ё` на `е` и удаляет дубликаты. В проверенном архиве после обработки загружается **4143 уникальных слова**.

Неверный формат ввода и слова, отсутствующие в словаре, не расходуют попытку. Повторный ввод уже проверенного слова пока не запрещён и расходует ещё одну попытку.

## Тестирование

В шести тестовых классах содержится **74 метода `@Test` на JUnit 5**. Они проверяют:

- загрузку и нормализацию словаря;
- фильтрацию слов и обработку ошибок;
- сравнение букв, в том числе повторяющихся;
- подсказки и ограничение количества попыток;
- выигрышный и проигрышный сценарии;
- взаимодействие компонентов приложения.

Для запуска тестов в IntelliJ IDEA подключите JUnit 5 из каталога `lib/`, если IDE не обнаружит библиотеки автоматически. Пометьте `test/` как **Test Sources Root** и запустите тестовые классы.

**Примечание:** один тест (`isWordGuessed_WrongWord_ReturnsFalse`) зависит от случайного выбора загаданного слова, поэтому может нестабильно проходить. Для воспроизводимых тестов лучше передавать генератор случайных чисел или заранее заданное слово через конструктор.

## Известные ограничения

- Это консольная игра без графического интерфейса, REST API и сохранения статистики между запусками.
- Алгоритм подсказок эвристический: не гарантирует оптимальный вариант. Если подходящих кандидатов не найдено, может предложить слово, не согласующееся с предыдущими подсказками.
- Повторные попытки с одним словом допускаются.
- Тесты не полностью детерминированы из-за случайного выбора слова.
- Файл `wordle.log` создаётся во время запуска и содержит загаданное слово, поэтому его не следует хранить в Git.
- Для словаря `words_ru.txt` следует отдельно проверить происхождение и условия использования перед дальнейшим распространением.
